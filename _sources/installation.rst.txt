Installation
============

From Source
-----------

::

    cargo install --path .

From crates.io (When Published)
-------------------------------

::

    cargo install ingot

Prerequisites
-------------

- Rust toolchain (1.70+)
- For running generated tests: CMake 3.10+, a C99 compiler, and the Unity
  test framework (included as a git submodule in ``deps/unity``)
